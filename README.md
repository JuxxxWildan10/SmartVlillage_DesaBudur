# Sistem Informasi Smart Village - Desa Budur

Sistem Informasi Terpadu (Smart Village) Desa Budur adalah sebuah platform digital yang dirancang untuk mempermudah pelayanan administrasi masyarakat, meningkatkan transparansi desa, dan memfasilitasi interaksi antara warga dan pemerintah desa.

Proyek ini dibangun sebagai dedikasi dan program kerja oleh **Kelompok 11 KKN Universitas Nahdlatul Ulama (UNU) Cirebon Tahun 2026**.

## 🚀 Fitur Utama

Aplikasi ini dibagi menjadi 2 pilar utama: **Portal Warga (Publik)** dan **Panel Admin**.

### Layanan Warga
- **e-Surat**: Pengajuan surat keterangan secara online tanpa harus datang ke balai desa, lengkap dengan fitur pelacakan (tracking) dan unduh PDF ber-QR Code.
- **Pengaduan Masyarakat**: Warga dapat melaporkan masalah infrastruktur atau pelayanan, dilengkapi lampiran foto.
- **Transparansi APBDes**: Menampilkan visualisasi data anggaran pendapatan dan belanja desa.
- **Katalog UMKM**: Etalase digital untuk mempromosikan produk-produk usaha mikro kecil dan menengah warga Desa Budur.
- **Cek Bansos**: Fasilitas mandiri warga untuk mengecek status penerimaan Bantuan Sosial menggunakan Nomor KK.
- **Forum Diskusi & Berita**: Wadah komunikasi dua arah dan portal informasi resmi desa.

### Panel Pemerintahan (Admin)
- **Manajemen Kependudukan**: Kelola data NIK, KK, mutasi penduduk.
- **Manajemen Pemerintahan**: Kelola struktur Aparatur Desa, Posyandu, dan pembaruan skor SDGs (Tujuan Pembangunan Berkelanjutan).
- **Verifikasi Dokumen**: Admin dapat menyetujui/menolak surat serta membalas keluhan warga secara langsung.

## 🛠️ Teknologi yang Digunakan

Aplikasi ini menggunakan arsitektur modern (*Headless CMS / Decoupled Architecture*):

- **Frontend**: [Next.js](https://nextjs.org/) (React), Tailwind CSS, TypeScript
- **Backend**: [Laravel 11](https://laravel.com/) (PHP), Sanctum API Authentication
- **Database**: MySQL / PostgreSQL
- **Role Management**: Spatie Permission
